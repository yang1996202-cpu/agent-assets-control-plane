- **状态**：🟢 已完成
- **添加**：2026-06-20
- **完成**：2026-07-03
- **简述**：静态 HTML + 本地 HTTP 服务，展示资产、MCP audit、runtime、系统信号四大视图，支持一键扫描、review 决策、launchctl 开关、进程终止。
- **历史沿革**：
  - [2026-06-20] 初始版本：基于 registry 生成总览页。
  - [2026-06-26] 定位演进为运行态观测台，新增系统信号、runtime、8 分类模型。
  - [2026-07-03] 模块化重构：拆分为 `lib/agent_assets_dashboard_*.py`，补单元测试。
  - [2026-07-03] 新增「系统进程」tab 与 runtime 内存列：展示全部进程并支持筛选，`asset-runtime` 进程行携带 RSS 内存字段。

### Runtime 进程盲区扫描
- **状态**：🟢 已完成

- **历史沿革**：

### 系统进程监视
- **状态**：🟢 已完成
- **添加**：2026-07-03
- **完成**：2026-07-04
- **简述**：dashboard 新增「系统进程」tab，展示本机全部进程（含 GUI 应用）。页面顶部展示「高 CPU / 高内存」占用进程，表格按应用名称聚合，避免 Chrome / WeChat 等大量 Helper 进程把列表撑爆；支持按类别筛选与表头排序。
- **历史沿革**：
  - [2026-07-03] 新增系统进程视图：`bin/agent-assets-runtime` 输出 `rss` 字段；dashboard 增加「系统进程」tab 与内存列渲染。
  - [2026-07-03] 增加 CPU 字段、进度条可视化、表头排序，支持采集 GUI 应用进程。
  - [2026-07-03] 进程分类规则与用户环境映射外置到 `~/.config/agent-assets/runtime-classification.json` / `product-map.json`。
  - [2026-07-04] 参考 Stats 风格重构：顶部新增「高占用进程」卡片（Top 5 CPU + Top 5 内存）；表格按应用名称聚合，消除 Chrome / WeChat / Electron Helper 重复行；批量终止支持聚合进程组。
  - [2026-07-04] 修复 `_pid_exists` 对 root 系统守护进程权限错误的处理，避免「运行中」被误判为「未运行」；修复 `state_badge` 覆盖自定义状态文案的问题。
  - [2026-07-04] 新增「内存总览」卡片：基于 `vm_stat` + `sysctl` 展示总内存、已用、App、联动（Wired）、被压缩、缓存文件与可用内存，解释进程列表合计与系统总占用的差异。
